## 语言偏好

### 喜欢
- 短句，一句一个信息
- 因果链完整（因为→所以）
- 定量证据（数字、比例、时间）
- 对比/类比帮助理解
- 恰当的古诗或成语点睛
- 技术术语保持英文原词
- README 标题用 Emoji 点缀（如 📦 安装、🚀 快速开始、⚙️ 配置、🔧 开发）

### 不喜欢
- 网络梗、流行语、饭圈用语
- 企业/政府报告腔
- AI 模板化表达
- 三段式结构（不仅……更是……还……）
- 意义膨胀词（彰显、体现、标志着）
- 模糊引用（专家表示、引发关注）
- 祈祷式结尾（未来可期、前景广阔）

### 绝对不能出现
- yyds、绝绝子、懂的都懂、家人们、破防了
- 赋能、闭环、抓手、对齐、颗粒度、底层逻辑、打法、复用
- 值得注意的是、不可忽视的是、毋庸置疑、众所周知
- 在……的大背景下、随着……的深入发展

## 文化引用规范

### 数量
- 一篇技术文档：最多 1-2 处
- 少就是好。不引用也不扣分。

### 出处范围
- 优先：中小学语文课本常见古诗、成语
- 可接受：四书五经常见名句
- 避免：冷门典故、"小众"诗词
- 避免：西方谚语（除非特别贴切）

### 常用库（持续扩充）

**技术写作常客：**
| 引用 | 适合场景 |
|------|---------|
| 纸上得来终觉浅，绝知此事要躬行 | 理论 vs 实践 |
| 不畏浮云遮望眼 | 透过表象看本质 |
| 只缘身在此山中 | 视角/盲区 |
| 苟日新，日日新，又日新 | 迭代/持续改进 |
| 不积跬步无以至千里 | 渐进效果 |
| 水滴石穿 | 持续积累 |
| 过犹不及 | 不要过度 |
| 欲速则不达 | 别急 |
| 九层之台起于累土 | 基础重要 |
| 千里之堤溃于蚁穴 | 小问题变大 |
| 南辕北辙 | 方向错了 |

## 句式节奏

### 典型段落模板

```
[结论句]。[展开句/因果句]。[数字/证据]。[对比或总结]。
```

**示例：**
> SQLite 不适合高并发写入。（结论）
> 它的锁机制是表级锁，写操作会锁住整张表。（因果）
> 实测 100 个并发写入时，TPS 从 5000 跌到 47。（证据）
> 同样的场景 PostgreSQL 能做到 8000 TPS。（对比）

### 段落过渡方式

- 直接用内容过渡，不用连接词
- 必要时用"但""不过""同时"
- 绝对不用"与此同时""另一方面""除此之外"
