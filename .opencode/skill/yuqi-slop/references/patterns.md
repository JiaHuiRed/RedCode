# 中文 AI 味模式清单

## 一、膨胀动词

AI 写中文习惯给每个动作加个"高级"外衣，去掉意思不变。

| AI 用语 | 替换方案 |
|---------|---------|
| 标志着 | 是、意味着、直接说结果 |
| 彰显了 / 凸显了 | 直接说事实 |
| 体现了 / 展现了 / 诠释了 | 直接说事实 |
| 揭示了 / 反映了 | 是、说明 |
| 赋予了 / 注入了 | 给了、带来 |
| 夯实了 | 加强了 |
| 推动了 / 促进了 | 带了、让 |
| 助力了 / 赋能了 | 帮了 |
| 激发了 / 释放了 | 让……出来 |
| 催生了 / 孕育了 | 有了、出了 |

**典型例句：**
> 这一改革举措充分彰显了政府优化营商环境的坚定决心。
> → 这次改革把开公司的审批时间从30天压到了3天。

## 二、企业套话

中文 AI 特别容易写成企业官网 / 政府工作报告风格。

| AI 用语 | 替换方案 |
|---------|---------|
| 我们深知 | 我们知道、删掉 |
| 我们坚信 | 我们觉得、我们赌 |
| 我们始终 | （删掉） |
| 我们致力于 | 我们在做 |
| 秉承……理念 | 按照…… |
| 以……为核心 | 主要做…… |
| 依托……优势 | 靠…… |
| 深耕……领域 | 做了……年 |
| 赋能……转型 | 帮……转型 |
| 打造……生态 | 做平台 |
| 构建……体系 | 搭了一套 |

**典型例句：**
> 我们致力于为客户提供一站式数字化转型解决方案。
> → 我们帮传统商场做小程序和线上商城。

## 三、填充引导

AI 拿来凑字数的开场白。

### 段落开头型
- 值得注意的是， / 不可忽视的是， / 需要指出的是，
- 众所周知， / 不言而喻， / 毋庸置疑的是，
- 从某种意义上来讲， / 在某种程度上，
- 纵观全局， / 从整体来看，
- 总的来说， / 概括而言，

### 段落过渡型
- 与此同时， / 另一方面， / 除此之外，
- 不仅如此， / 更有甚者，
- 话又说回来， / 换个角度来看，
- 值得一提的是， / 无独有偶，

**规则：** 90% 的情况下这些词可以直接删掉，剩下的 10% 用"但""而且""也"替代。

## 四、模板化开头

AI 写段落第一句的模式。

| 模式 | 问题 |
|------|------|
| 在……的大背景下 | 废话铺垫 |
| 随着……的深入发展 | 废话铺垫 |
| 在……的浪潮中 | 废话铺垫 |
| 近年来，…… | 除非有明确时间对比，否则删 |
| 当前，…… | 换成具体时间或直接说事 |
| 进入……新阶段 | 直接说阶段是什么 |

**规则：** 第一句直接说事，别绕。

## 五、意义空洞词

| 词 | 问题 | 替换 |
|----|------|------|
| 前所未有 | AI 最爱 | 具体说哪里不一样 |
| 颠覆性 | 99% 的情况不颠覆 | 重要的 |
| 革命性 | 同上 | 新的 |
| 突破性 | 同上 | 改进的 |
| 里程碑 | 少用 | 第一步 / 关键节点 |
| 引领 | 除非真有人跟着走 | 带动 |
| 首例 / 首个 | 确认事实后再用 | |

## 六、模糊引用

AI 编不出具体名字时的万能模板。

| 模板 | 问题 |
|------|------|
| 业内人士指出 | 哪个业？谁？ |
| 专家表示 | 哪位专家？ |
| 有关方面透露 | 哪个方面？ |
| 消息人士称 | 消息人士在哪？ |
| 研究报告显示 | 哪个报告？ |
| 引发广泛关注 | 哪里关注？多少人在关注？ |
| 备受社会各界瞩目 | 同上了 |

**规则：** 要么给具体出处，要么删掉整句。

## 七、并列堆砌

AI 喜欢一口气列三四五六七八个名词。

| 模式 | 问题 |
|------|------|
| A、B、C、D 等多个领域 | 说核心的两个就够了 |
| 从 A 到 B，从 C 到 D | 假范围 |
| 以及……以及…… | 一个"和"就够了 |
| 既……又……还…… | 选最重要的一个 |

**规则：** 并列不超过三项。超过三项就是堆砌。

## 八、三段式结构

| 模式 | 例子 |
|------|------|
| 不仅……更是…… | 不仅是技术升级，更是理念革新 |
| 既是……也是……还是…… | 既是挑战，也是机遇，还是考验 |
| 无论……还是……抑或…… | 无论是个人还是企业抑或政府 |
| 从……到……再到…… | 从研发到生产再到销售 |

**规则：** 三段式是 AI 最明显的结构特征。拆成一句话直接说完。

## 九、被动无主语句

| 模式 | 问题 |
|------|------|
| 被广泛应用 | 谁用？ |
| 被认可 | 谁认可？ |
| 被提出 | 谁提出的？ |
| 被纳入 | 谁纳入的？ |

**规则：** 能找到主语就加主语，找不到就说明是推测。

## 十、AI 语气词

| 词 | 感觉 |
|----|------|
| 我们相信 | 企业宣传稿 |
| 让我们一起 | 演讲结尾 |
| 我有信心 | AI 被问到"你确定吗"时的标准回复 |
| 当然 | 看似自信，其实在拖字数 |
| 实际上 / 事实上 | 前面那句大概率是废话 |
| 不可否认 | 接下来要替对方说话了 |
| 无论如何 | 结论是编的 |

## 十一、完美过渡词映射

| AI 用 | 人用 |
|-------|------|
| 与此同时 | 但也 / 同时 /（直接新段落） |
| 另一方面 | 但 / 不过 |
| 除此之外 | 还有 /（直接说） |
| 值得一提的是 |（删掉） |
| 无独有偶 | 同样 |
| 话又说回来 | 但不过 /（直接转折） |

## 十二、标点滥用

| 标点 | AI 特征 | 规矩 |
|------|---------|------|
| 破折号 —— | 一段话超过 1 个 | 全改成逗号句号 |
| 引号 "" | 给普通词加引号 | 不用引号的词别加 |
| 分号 ； | 非正式文体里滥用 | 写成两个句子 |
| 感叹号 ！ | 连续多个 | 一段话最多一个 |
| 省略号 …… | 装深沉或装犹豫 | 直接说 |
