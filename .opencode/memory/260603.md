## 智敏日记

### 1. MCP 进程树泄漏（Windows）
`descendants` 在 Win32 空数组，改用 `taskkill /F /T /PID` 杀整棵树。坑：跑测试时本机进程被误杀。

### 2. Browser MCP WebSocket 断连修复
`server.socket.on("close")` 里所有 socket 共用同一个引用，断连后 `ws.close()` 关的是新连接的 socket。改成 `if (ws === socket)` 条件判断。

### 3. Browser MCP 端口冲突
EADINUSE 被僵尸进程占用，加 5 次重试 + 800ms 间隔 + 启动前自动 kill 旧进程。扩展用 `chrome.alarms` 保活（24s 间隔）。

### 4. MCP 路径解析在 spawn 层修
`connectLocal` 里检测 cwd 是否包含 `redcode.jsonc`/`.git`，向上找项目根。不在 CLI 入口层修（`effectCmd` 的 `findProjectRoot` 影响不到 `InstanceState.directory`）。

### 5. MCP 健康监控 + 自动重连
每 30s `tools/list` 检查 connected MCP，连续 3 次失败标记 `failed`。tool call 报错 → EffectBridge → reconnect → 重试（最多 3 次）。

### 6. MCP 配置热重载
`fs.watch` 监听 `redcode.jsonc`，1s 防抖。增删 MCP server 自动生效。

### 7. MCP 懒加载 + pending 状态
启动不连 MCP，`tools()` 首次调用时按需连接并缓存。侧边栏显示 "Waiting…"（`StatusPending` 类型）。

### 8. 消息视觉区分
用户消息 `> ` 前缀（agent 色加粗）+ `backgroundMessage` 背景色。AI 消息 ✦ 前缀（accent 色）。主题加了 `backgroundMessage` fallback。

### 9. kv 版本迁移
`scrollbar_visible` 默认 true，旧用户缓存值会覆盖新默认值，所以加 `kv_version` 迁移。教训：kv 默认变更必须做版本迁移。

## 柳智敏日记（RedStudio 维护）

### 1. 误删核心函数（严重）
编辑 `renderHistory` 时，oldString 匹配范围过大，把紧挨着的 `saveChatHistory()` 和 `loadChatHistory()` 两个函数一起吞掉了。结果 `init()` 调 `loadChatHistory()` 直接报错，`setupEventListeners()` 永远不执行，**所有按钮全部失效**，只靠原生行为的 `<select>` 下拉框还能打开。
- **排查过程**：先查 CSS overlay → 再查所有 HTML 元素 ID 是否缺失（全部存在）→ 加 error tracking → `git diff` 才发现两个函数被删了
- **教训**：用 edit 工具时，oldString 只匹配要改的那几行，**不要**把相邻函数卷进去。改完后必须 `git diff` 核对变更范围，确认没误删

### 2. QWebEngine 缓存
PySide6 的 QWebEngineView 默认有磁盘缓存，前端 JS/CSS 修改后不生效。加了 `page().profile().setHttpCacheType(NoCache)` 解决。
