# 260604 每日日志

## 雨琦日记

### 1. 标题栏版本号写死漂移（0.3.17 根治）
`index.html` 标题栏徽章一直硬编码 `v0.3.16`，每次升级靠手改、漏改就编出旧版号。改成占位符 `__RC_VERSION__`，`electron.vite.config.ts` 加 `redcode:inject-version` 插件 build/dev 时从 `package.json` 注入。教训：能从单一来源自动注入的，绝不留第二处手填。

### 2. EBUSY 构建坑——查了半天竟是自己挖的
desktop bat 打包时 `afterAllArtifactBuild` 把 `win-unpacked` 改名 `win` 反复 `EBUSY: rmdir dist\win`，静默 catch 还照打 "Done"，留下旧 0.3.15。`tasklist` 没抓到 RedCode/node 进程，一度怀疑 Defender。真相：**有进程把空目录当 CWD（当前工作目录）就会让 rmdir 报 busy**——是调试时从 `dist\win` 启动 exe 留下的几个卡死 shell，CWD 钉在那。教训：①重建前先关掉从输出目录启动的 exe、排查 cd 进去的僵尸 shell；②查目录锁用读 PEB CurrentDirectory 扫所有进程 CWD（`NtQueryInformationProcess`），比猜进程名靠谱；③静默 catch 是帮凶，构建失败必须 throw 报错，别假装 Done。

### 3. bat 编码坑
`Write` 工具存 UTF-8，但 cmd.exe 按系统 OEM 码页（中文机 GBK）读 `.bat`，中文 `rem` 注释字节被打乱，连累 `rem`/`copy`/`exit` 整行解析错。教训：**bat 注释一律纯 ASCII/英文**，跨机/git 回家都不炸。

### 4. 通知图标死域名
`index.tsx` 通知图标硬连未注册的 `redcode.dev/favicon...`，每次弹通知 DNS 失败刷 `ERR_NAME_NOT_RESOLVED`。改基于 `document.baseURI` 解析本地打包图标。

## 智敏日记

### 1. simplify skill 落地（普适性定论）
新增 `simplify` skill（识别过度工程、把代码改回刚好够用）。落点 = 仓库 staging `.opencode/skill/<name>/SKILL.md` + build.bat 同步到 `~/.redcode/skill/`。理由：home `~/.redcode` 被引擎**无条件扫描**=每项目每台机器都加载，是唯一真普适载体；放仓库 `.redcode/skill/` 只在本仓库内被 up-walk 扫到、出仓库失效且和 home 镜像双重加载。教训：跨机能力放 home hub，别放项目目录。

### 2. 两个 bat 同步漂移——治本
`opencode/build.bat`（全量同步 souls/hub/skill）和 `desktop/build-and-package.bat`（旧版只同步 souls/MEMORY/AGENTS）早已分叉，跑哪个 home 拿到的东西都不一样——正是版本号坑的同类隐患。抽 `script/sync-home.bat` 单一来源，两个 bat 都 `call` 它。教训：同一逻辑出现在两处=迟早分叉，抽共享。

### 3. hub 注入器进 git
新增 `.opencode/redcode.home.jsonc`，build.bat 从零重建 `~/.redcode/redcode.jsonc`（`instructions` 注入链命门）。清白机器 pull + 跑 bat 即得完整 home。USER.md 不进 git（哥哥微信转发，家里已有初步画像）。

### 4. 斜杠命令从未实装——`.opencode/command` 引擎不扫
哥哥发现 `/宋` `/敏` 两端都出不来。查根因：`config/paths.ts` 的 `directories()` 只扫名为 **`.redcode`** 的目录（项目 up-walk + home），**根本不扫 `.opencode/`**；命令却全放 `.opencode/command/`。`config/command.ts` 的 `load(dir)` 扫 `{command,commands}/**/*.md`，但 dir 来自 `directories()`——所以 `.opencode/command/*.md` 从来没被加载，连 `/commit` 那些老命令一起没实装。sync-home 此前同步了 skill 却漏了 command。修：sync-home 补同步 `.opencode/command` → `~/.redcode/command`（真镜像，先删后拷）。教训：**凡是放 `.opencode/` staging 的新资源类型（command/skill/...），必须在 sync-home 里补一条同步到 home 镜像，否则引擎只认 `.redcode` 永远看不见**。

### 5. 中文命令名 → 英文（免切输入法 + bat 注释零中文）
命令名 = 文件名，中文 `宋.md`/`敏.md` 打命令要切输入法。改成 `son.md`（宋雨琦/小宋）`Karina.md`（柳智敏/敏敏）。同时险些在 sync-home 的 `rem` 注释里写中文（违反 bat 纯 ASCII 铁律，会被 GBK 读乱），立刻改回英文。
