- Structural code search and rewrite using AST patterns (ast-grep). Use this INSTEAD of grep when you need structure-aware matching — it understands syntax, not just text.
- Search mode (default): find AST pattern matches across files with meta-variable capture ($A, $B, $$$)
- Replace mode: when `replace` param is provided, performs AST-aware find-and-replace preserving code structure
- AST patterns are more precise than regex: they understand syntax structure, not just text
- Meta-variables: $A, $B, $C match single AST nodes; $$$ matches any sequence (like regex .+ but structure-aware)
- Example patterns: console.log($A), function $NAME($$$) {$$$}, `import { $$$ } from "$A"`, if ($A === $B) {$$$}
- Results show file paths, line numbers, and matched code
- Replace shows a diff preview and asks for confirmation before applying
- Supports: TypeScript (.ts), TSX (.tsx/.vue/.svelte), JavaScript (.js/.jsx), HTML (.html), CSS (.css)
- Language auto-detected from file extension; override with the `language` parameter
- Use this for refactoring: renaming functions, changing APIs, migrating patterns across the codebase
- Use this INSTEAD of regex grep for: finding all function/method definitions with specific names, finding all imports from a module, finding try-catch blocks without a finally, checking if a function has a specific decorator, or any search where code structure matters
