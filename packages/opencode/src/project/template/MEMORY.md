# RedCode 记忆系统

> 🧠 这是你的工作记忆模板。把这里的内容换成你自己的教训、偏好和规范。
> 完成后保存到 `~/.redcode/MEMORY.md`（全局生效）或 `项目根/.opencode/MEMORY.md`（项目级）。

**使用说明：**

- `memory/YYMMDD.md` — 每日日志，自动记录工作过程
- `MEMORY.md` — 长期库，从每日日志提炼关键教训
- 格式自由，只记录对你重要的事
