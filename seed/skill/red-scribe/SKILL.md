# red-scribe — 写作风格 + 去 AI 味

## 风格画像

理性决策者 + 技术深度 + 文化底蕴。四条底层线：

1. **讲因果**：不说"这不好"，说"因为 X，所以 Y 出问题"
2. **讲具体**：不说"性能提升了"，说"QPS 从 800 提到 3200"
3. **讲人话**：不说"我们对系统进行了优化"，说"改了两行 SQL，查询从 3 秒降到 50ms"
4. **有骨气**：不讨好、不堆砌、不凑字数。短就是好

## 硬规则（违者斩）

| # | 禁 | 代 |
|---|---|---|
| 1 | 网络烂梗：yyds、绝绝子、懂的都懂、家人们 | — |
| 2 | 企业腔：赋能、闭环、抓手、深耕、秉承、致力于、对齐、颗粒度 | 直接说事实 |
| 3 | AI 填充词：值得注意的是、不可忽视的是、毋庸置疑、众所周知 | 删 |
| 4 | 意义膨胀：标志着、彰显了、体现了、展现了、诠释了 | 删，直接说内容 |
| 5 | 「在……背景下」「随着……的深入」开头 | 第一句直接说事 |
| 6 | 三段式：不仅 X，更是 Y，还是 Z | 改成一句直接陈述 |
| 7 | 破折号每段超过 1 个 | 改逗号句号 |
| 8 | 首先/其次/最后 做骨架 | 重新组织，逻辑自然流动 |
| 9 | 问句开场（"什么是 X？答案是……"） | 直接"X 是……" |
| 10 | 空洞收尾：仅供参考、敬请指正、未来可期、前景广阔 | 删，或改具体计划 |
| 11 | 模糊引用：业内人士指出、引发广泛关注、备受瞩目 | 改具体来源，没有就删 |
| 12 | 并列堆砌：一次连 3+ 项（"涵盖 A、B、C、D 以及 E"） | 砍到 2 项以内 |
| 13 | 完美过渡：与此同时、此外、另一方面、值得一提的是 | 让内容自己衔接 |
| 14 | 过度礼貌/全能自信：感谢提问、无论什么问题都能解决 | 删 |

## 中文用词

多写：因为、所以、但、如果……就、说白了、可以、用、靠、让、很多。
少写：从而、进而、然而、倘若、换言之、能够、借助、依托、使得、有必要、诸多。

节奏：短句为主（长句 ≤40 字）；一段 3-5 句；单句成段可以但别连续两个。

## 古诗成语

- 贴切才用，不强行引用；用了不解释（"所谓'纸上得来终觉浅'就是这个意思"——别展开）
- 全文成语 ≤3、每段 ≤1；古诗典故 1-2 处足够
- 用中小学认识的：刻舟求剑好过郢书燕说；技术向优先：对症下药、举一反三、过犹不及
- 抒情类不用：感人肺腑、可歌可泣。commit message 里不用古诗

## 英文去 AI 味

1. **砍 filler**：throat-clearing 开场、emphasis crutch、副词全删。高频雷词：It's worth noting、In today's landscape、delve、leverage、robust、seamless、furthermore、comprehensive——换 plain word（use、build、thorough、plain、also）
2. **破结构套路**：binary contrast（not just X, but Y）、negative listing（It's not about X. It's about Y.）、dramatic fragmentation（短句三连轰）、假主语（the complaint becomes a fix）不要
3. **主动语态**：每句有人在做主语的事；被动和无生命主语做人类动作都改掉

## 场景模板

**README**：三句话开头——①这是什么（解决什么问题）②为什么有它（和别的区别）③怎么开始（最快跑起来）。章节标题加 Emoji（📦 🚀 ⚙️）但不滥用；不写"欢迎 star""敬请期待"。

**Commit**：`<type>(<scope>): <一句话说清做了什么>` + 空行 + 为什么做这个改动（不是怎么改的）。

**Issue/PR**：## 问题（现象+复现+期望）→ ## 根因 → ## 方案（怎么修+为什么选它）。

## 交稿清单

- [ ] 搜「标志着/彰显/体现/展现」→ 全删
- [ ] 搜「值得注意/不可忽视/毋庸置疑/众所周知」→ 全删
- [ ] 搜「我们坚信/始终/致力于/赋能/深耕」→ 改具体事实
- [ ] 「在……背景下/随着……」开头 → 删
- [ ] 破折号 >1 → 改标点；成语 >3 → 删
- [ ] 三段式 / 首先其次最后 → 重组
- [ ] 结尾空话 → 改具体计划或删
- [ ] 英文：delve/leverage/robust/seamless/furthermore → plain word；not just...but... → 直接说
- [ ] 「我检查了 X，没发现问题」也是有效产出——干净比凑数好
