# docs

按文档性质分目录；新增文档放进对应目录，不要直接堆在根下。

| 目录          | 放什么                                                                   |
| ------------- | ------------------------------------------------------------------------ |
| `audits/`     | 审计报告与任务书：第三方工程审计、GUI 交互摩擦、harness 落地、TUI 功能审计 |
| `experience/` | 体验/UX 线：优化建议、接力清单、体验审查、整合路线图                     |
| `plans/`      | 方案、路线图与交接快照：子代理角色与派发、DSH 采纳、并行系统收口、computer use |
| `prompt/`     | 提示词与伙伴对话设计：修订提案、固定前缀实验、行为契约                   |
| `reviews/`    | 版本复审收尾报告（按版本号命名）                                         |
| `notes/`      | 技术决策记录，四态目录 + 主题子目录，规则见 `notes/README.md`            |
| `previews/`   | 单页 HTML 预览                                                           |
| `assets/`     | 截图与品牌素材                                                           |

两个留在根下的配置属于运行时契约，不进分类目录：

- `injection-registry.jsonc` — 注入项登记表，`script/check-injection-registry.ts` 读取
- `prompt-patches.yml` — 提示词时效性补丁台账

历史文档保持写就时的结论；搬迁只改指向路径，不改内容。
