# Yuqi：午夜蓝紫、赤红与金色

状态：implemented

## 决策

- 首版低彩度石墨与薄荷青经实机反馈有灰绿、青苔观感，不再沿用。
  最终采用午夜蓝紫底、赤红交互色、蓝紫关键字与金色字符串；浅色对应淡紫雾白，不调整用户字体。
- 色板与正文、代码、输入框、浮层颜色由 `themes/yuqi.json` 管理；v2 中性色继续沿用
  既有生成器，不改明度曲线或其它主题。代码背景暗色 `#2b2040`、浅色 `#f0eafb`。
- `app/src/index.css` 的新增规则全部限定 `data-theme="yuqi"`。降低玻璃掺色比例，
  统一 v1/v2 强调色；暗色实色控件的填充再混入底色，保留白色指示符的对比度。
- 代码块用细描边、内高光和极浅的静态迎光渐变；行内代码与引用保持轻量层次。
  输入框聚焦只增加清晰的细环，不添加持续运动、霓虹辉光或新的交互逻辑。
- 侧栏玻璃染色从 `syntax-property` 青色改取 `syntax-keyword` 蓝紫色；成功与 diff 新增仍保留绿色语义。

  做明暗对照；真实点击确认焦点环，1600px 与 900px 视口无样本横向溢出。
